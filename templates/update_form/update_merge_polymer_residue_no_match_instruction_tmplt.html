How to address the "No Hit found from Graph Match Search" instance(s) due to geometry issue if the modified amino acid residue ID(s) is(are) known:
  • Click the "Edit / Create New Ligand" link to open the "Chemical Component Editor" tab
  • Check the graph inside the Chemical Component Editor to see if they are any missing/extra bonds due to bad geometry
  • Edit the graph by adding missing bond(s)/removing extra bond(s) inside Chemical Component Editor
  • Save the editing by click the "Save" button and close the "Chemical Component Editor" tab
  • Put the modified amino acid residue ID into the "CC ID:" box
